# V3.0 体验设计 — 智能客服

> 基线：`.stitch/DESIGN.md`（全站设计契约）+ `docs/02-design/设计系统.md`。本文只写 V3.0 新增页面的设计决定，色/字/间距/组件沿用基线，不另造体系。

## 1. C 端入口（对照支付宝左下角 AI 助手）

- **H5**：`MallLayout` 内固定悬浮 AI 头像球，锚定 TabBar 左上方（`left:12px; bottom:calc(tabbar + 12px)`），直径 48px，圆形，品牌绿底 + 白色「AI」字样（用品牌色 `--brand` 系变量，不用紫），入场一次轻微上浮动画；列表页与首页显示，详情/结算等 `hideTab` 页隐藏。
- **Web**：右侧 `web-float-rail` 首项加「AI 助手」（星形/对话图标 + 文案），点击进 `/ai`。

## 2. AI 助手页（`/ai`，Web∥H5 同构）

- 布局：顶栏（标题「AI 助手」+ 历史会话入口 + 新对话）；消息流区；底部输入区（输入框 + 发送按钮，H5 吸底避让 TabBar）。
- 会话恢复：进入 `/ai`（含刷新、从商品详情返回、从站内入口再次进入）时自动回放当前进行中会话的消息与商品卡片；历史为空才展示欢迎语。点「新对话」才结束旧会话并新建，旧会话保留在历史会话中。
- 历史恢复：最近 50 条先回放，超过后可「加载更早消息」；历史商品卡标注“历史商品卡 · 价格/库存以详情页为准”；历史回放不展示思考链。
- 待确认动作：恢复未过期的 `pending_action` 卡片，只读展示，用户主动确认/取消后才执行。
- 异常恢复：历史消息加载失败时显示重试并禁用输入，避免在缺少上下文的情况下继续发送。
- 空闲结束：最后一条消息（用户或助手）超过 30 分钟未更新，会话自动结束；再进入时新建会话并提示上一场已结束，旧会话只读。
- 多端：同一账号不同浏览器/设备使用独立的 `client_key`，不互相串会话。
- 气泡：会员右蓝、智能客服左白（头像=入口同款 AI 球缩小版）、坐席左白带「人工客服」角标。
- 思考中：AI 气泡内「思考中…」占位，`reasoning` 事件到达后折叠展示思考摘要（默认收起，点开看滚动原文），正文 `delta` 到达后逐字上屏。
- 商品卡片：横向大卡（图左文右），字段图/名/副标题/价格区间/销量，点击整卡进详情；一次回答 ≤3 张，纵向排列。
- 商品卡操作（v3.4.3）：卡片底部提供「加入购物车」按钮；点击只传 `spuId`，后端按当前商品名走同一加购/确认链路。金额 ≥500 或数量 >1 生成待确认卡；单 SKU 且金额 <500 直接加购；多 SKU 先反问规格。自然语言“现在买/把手机加进购物车”仍保留为兜底。
- 多规格快捷选项：多规格回答中的 `【规格N】` 渲染为 chip，点击发送 `规格N`；后端承接上一轮商品上下文，直接加购/确认，不再重新问商品。
- 快捷问题：空会话首屏展示 4~6 个 chip；历史回放不展示。
- 转人工：输入区上方常驻文字链「转人工」；转人工后显示会话状态条（排队中/人工服务中）。
- 降级态：`degraded=true` 的回答顶部加浅黄提示条「智能助手暂时繁忙，以下为兜底建议」。
- 空态/错误态：网络错误气泡内联「重试」；会话已结束只读并提供「再开一场」。

## 3. 管理端（Element Plus，沿用既有列表页范式）

- 「智能客服」目录 + 6 菜单页：会话管理（状态 Tab + 详情抽屉式对话窗 + 接入/回复/转接/结束）、客服工单（列表 + 状态流转）、知识库（表格 + 编辑抽屉 + 重建索引按钮 + vectorStatus 标签）、快捷回复（分组侧栏 + 话术表格）、坐席管理（表格 + 状态开关）、服务看板（4 指标卡 + 简单趋势）。
- AI 配置：复用系统设置页新增 LLM 分组表单（Key 密文展示、连通性测试按钮）。
