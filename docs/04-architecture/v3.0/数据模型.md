# V3.0 数据模型 — 智能客服（schema `customerservice`）

> 依据 `docs/03-ai/customer-service-智能客服.md` §2/§8 与 ADR-0005/0006。迁移脚本：`V22__v3_customerservice_schema.sql` 起。术语见统一语言文档。

## 1. 表清单

| 表 | 说明 | 关键字段 |
|---|---|---|
| `chat_session` | 会话 | `customer_id, client_type, status(AI_ONGOING/QUEUED/HUMAN_ONGOING/ENDED), seat_id, summary, started_at, ended_at` |
| `message` | 消息 | `session_id, role(USER/ASSISTANT/AGENT/TOOL), content_type(TEXT/PRODUCT_CARDS), content, metadata jsonb, reasoning TEXT, tool_trace jsonb` |
| `ticket` | 客服工单 | `session_id, customer_id, type(consult/complaint/refund/other), title, status(OPEN/PROCESSING/RESOLVED), seat_id, sla_due_at` |
| `seat` | 坐席 | `admin_user_id, nickname, status(ONLINE/BUSY/OFFLINE), max_concurrent` |
| `skill_group` / `seat_skill_group` | 技能组 / 关联 | `name` / `seat_id, skill_group_id` |
| `quick_reply_group` / `quick_reply` | 快捷回复 | 分组 `name, sort`；话术 `group_id, title, content, sort, is_recommended(推荐问)` |
| `knowledge_doc` | 知识文档 | `title, category(AFTER_SALE/FAQ/ACTIVITY/QA), content, status(DRAFT/PUBLISHED), version, vector_status(PENDING/DONE/FAILED), chunk_count` |
| `knowledge_chunk` | 知识切片（含向量） | `doc_id, seq, chunk_text, embedding vector(1024)` |
| `product_chunk` | 商品切片（含向量） | `spu_id, name, subtitle, category_name, price_min, price_max, sold_count, embedding vector(1024), refreshed_at` |
| `audit_log` | 审计 | `session_id, customer_id, event, risk(LOW/MID/HIGH), detail jsonb` |

通用列同基线：`id BIGINT PK(雪花)`, `created_at/updated_at TIMESTAMPTZ`, `deleted BOOL`, `trace_id`。逻辑删除遵循 MyBatis-Plus 全局配置。

## 2. 索引与扩展

- `CREATE EXTENSION IF NOT EXISTS vector`（pgvector 镜像自带扩展；外部库无权限时 DO 块跳过并走词法检索）。
- 查询列 B-tree 索引：会话（customer/status）、消息（session）、工单（status/customer）、切片（doc）、审计（time/event）。
- 向量索引：数据量 <1 万行不建 HNSW，检索用精确扫描；重建超阈值后另行迁移加 `USING hnsw (embedding vector_cosine_ops)`（注释占位，不写进 V22 行为）。

## 3. 中文词法检索约定

`LexicalRetriever` 不依赖中文分词扩展（镜像无 zhparser）：商品词法检索走 `commerce-api` 的关键词搜索（名称/副标题 LIKE，销量排序）；知识词法检索对本 schema 的 `knowledge_doc.content` 做应用层 **CJK bigram**（相邻两字）+ ASCII 词元的 `LIKE ANY(...)` 命中数打分。该实现细节属 ADR-0006 词法降级的一部分。

## 4. 系统配置键（`identity.system_config`，category=`LLM`）

| key | 默认 | 说明 |
|---|---|---|
| `llm.base-url` | `https://your-openai-compatible-gateway.example/v1` | OpenAI 兼容网关 |
| `llm.api-key` | （空，secret） | 置空且 .env 未配 → 降级模式 |
| `llm.model` | `cn:deepseek-v4.1-flash` | |
| `llm.temperature` | `0.5` | |
| `llm.system-prompt` | 内置默认 | 智能客服人设与硬约束 |
| `llm.embedding.base-url / .api-key / .model / .dim` | 空 / 空 / 空 / `1024` | 三项同填才启用向量 |
| `retrieval.mode` | `auto` | auto/lexical/vector |

`.env` 同名变量（`LLM_BASE_URL` 等）作默认值，`system_config` 覆盖 `.env`；密钥列 `is_secret=true` 不回显。

## 5. 菜单/权限种子（V22 内）

一级目录 `智能客服`（id 800）+ 会话管理(810)/客服工单(820)/知识库(830)/快捷回复(840)/坐席管理(850)/服务看板(860)，按钮权限码 `cs:session:*`、`cs:ticket:*`、`cs:kb:*`、`cs:quick:*`、`cs:seat:*`；全部授予超级管理员角色。AI 配置复用系统设置页 LLM 分组，不新增菜单。

## 6. V3.1 Agent 运行时表（V25）

| 表 | 用途 | 关键列 |
|---|---|---|
| `agent_run` | 一次用户任务 | session_id, customer_id, assistant_message_id, intent, agent, status, started_at/finished_at, total_tokens, model, prompt_version, error |
| `agent_step` | 图节点/子 Agent 步骤 | run_id, parent_step_id, node, agent, status, input_summary/output_summary, latency_ms, checkpoint_id |
| `llm_call` | 一次模型调用（流式结束后聚合） | run_id, step_id, model, tokens, latency_ms, finish_reason, status, request_ref/response_ref |
| `tool_call` | 一次工具调用 | run_id, tool_name, args_json, result_json, status, latency_ms, idempotency_key, error_code |
| `retrieval` | 一次 RAG 检索 | run_id, query, top_k, doc_ids, scores, hit, backend, latency_ms |
| `guardrail_event` | 护栏事件 | run_id, type, action, detail |
| `pending_action` | 写操作待确认 | session_id, run_id, tool_name, args_json, status, idempotency_key, result_json, expires_at |
| `feedback` | 用户反馈（P1） | run_id, session_id, type, score, comment |

约定：

- 状态值 `agent_run.status`：`RUNNING / OK / NEED_CONFIRMATION / NEED_USER_INPUT / HANDOFF / FAILED`。
- `pending_action.status`：`PENDING / CONFIRMED / CANCELLED / EXECUTED / EXPIRED`；失败保持 `CONFIRMED` 并在 `result_json.error` 记录原因，TTL 内可重试（ADR-0008）。
- `tool_call.idempotency_key` 部分唯一索引（`status IN ('RUNNING','SUCCESS')`）；`pending_action.idempotency_key` 全量唯一。
- JSONB 列依赖 JDBC `stringtype=unspecified`（应用默认 DB_URL 已带）；MyBatis-Plus 实体写走 `JacksonTypeHandler`，`LambdaUpdateWrapper` 不直接 set Map（避免 PG 当 hstore 绑定）。
- Trace 正文截断到 4KB，手机号/身份证落库前掩码；后续大 payload 可切 MinIO。
- 保留：`agent_run`/`agent_step`/`llm_call`/`tool_call`/`retrieval` 建议 30 天；`pending_action` 过期后 7 天清理；审计事件永久（按合规要求另定）。
